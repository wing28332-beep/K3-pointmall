# 游戏积分商城 / VIP中心 PRD

## 1. 文档信息

- 文档用途：说明积分商城活动页与 VIP 中心的功能逻辑，供开发实现与测试验收使用。
- 需求来源：基于现有 `K3-pointmall` 项目代码逻辑梳理。
- 适用端：H5 Web，兼容 PC 与移动端。
- 目标项目：游戏积分商城与 VIP 中心活动页。

## 2. 产品目标

为游戏玩家提供一个独立 H5 页面，支持玩家登录、选择/校验角色、查看积分余额与 VIP 经验、兑换积分商品、查看兑换记录、查看 VIP 等级权益、领取 VIP 礼包，并引导玩家跳转充值获取积分或升级 VIP。

核心目标：

- 提升充值后的积分消耗效率，提供可兑换商品列表。
- 提供 VIP 等级权益展示和礼包领取，强化会员成长感。
- 支持游客浏览，降低进入门槛。
- 支持多语言与多区服，为海外游戏复用。
- 支持完整埋点，跟踪访问、登录、角色校验、兑换、充值跳转等关键行为。

## 3. 用户角色

| 用户类型 | 权限/行为 |
| --- | --- |
| 游客用户 | 可浏览商品列表、VIP权益、活动规则；点击兑换、可兑换筛选、记录、礼包领取时引导登录。 |
| 已登录用户 | 可查看角色信息、积分、VIP经验、商品列表、可兑换商品、兑换记录、积分记录、经验记录、VIP权益、背包、礼包领取。 |
| 多角色用户 | 登录后可切换/校验角色，页面数据随角色刷新。 |

## 4. 页面结构

### 4.1 顶部导航

包含：

- 游戏 Logo。
- “获取积分 / 充值”按钮。
- 多语言下拉。
- 浮动客服按钮。
- VIP页时显示背包入口。

要求：

- 点击获取积分：未登录也允许跳转充值页；已登录时携带 `gameVersion` 与 `actorId`。
- 语言切换后刷新商品/VIP数据，并切换接口请求头语言。
- 客服入口需配置 `appName`、`entranceId`、客服平台参数。

### 4.2 用户信息区

未登录：

- 展示登录提示。
- 提供登录按钮。

已登录：

- 展示角色头像、VIP等级、角色名、角色ID、区服名、账号名。
- 展示积分与经验值。
- 点击积分打开积分记录弹窗。
- 点击经验打开经验记录弹窗。
- 支持切换角色/重新登录。
- 支持退出登录。

### 4.3 一级 Tab

页面包含两个主 Tab：

- 积分商城。
- VIP中心。

URL 支持 `?tab=vip`，进入页面时默认打开 VIP 中心。

## 5. 积分商城功能

### 5.1 商品列表

入口：默认展示。

数据来源：

- 游客：游客商品列表接口。
- 已登录：登录态商品列表接口。

展示字段：

- 商品图。
- 商品名。
- 上架时间。
- 下架时间。
- 商品内容，最多优先展示前 2 个道具。
- 所需积分。
- 每角色可兑换次数/剩余次数。
- 是否超值/热门标签。
- 兑换按钮。

商品图规则：

- 后端返回 `pic` 时展示远程图片。
- 图片为空或加载失败时展示本地兜底图。
- 点击商品图打开商品详情弹窗。

### 5.2 商品筛选

筛选项：

- 全部。
- 可兑换。

业务规则：

- 未登录用户点击“可兑换”时拉起登录。
- 已登录用户点击“可兑换”时，仅展示满足以下条件的商品：
  - 用户积分 `points >= 商品所需 points`。
  - 商品仍有兑换次数，代码中对应 `cycleTrade`。

### 5.3 商品详情弹窗

触发：点击商品图。

展示：

- 商品名称。
- 商品包含的道具列表。
- 道具图、道具名、数量。

规则：

- 道具图为空或加载失败时展示本地兜底图。
- 关闭弹窗后清空当前选中商品。

### 5.4 兑换确认

触发：点击商品兑换按钮。

前置校验：

- 未登录：拉起登录弹窗。
- 积分不足：弹出积分不足提示，并提供“获取积分”按钮。
- 商品不可兑换/次数不足：显示对应错误提示。

兑换确认弹窗展示：

- 商品名。
- 单价积分。
- 兑换数量。
- 总消耗积分。
- 确认按钮。

数量规则：

- 默认数量为 1。
- 仅允许输入正整数。
- 不得超过该角色剩余可兑换次数。
- 不得超过当前积分可支付数量。

兑换成功：

- 调用兑换接口。
- 关闭确认弹窗。
- 展示兑换成功弹窗，提示奖励到游戏内领取。
- 前端扣减本地积分。
- 更新商品剩余兑换次数。
- 重新计算可兑换商品列表。
- 更新积分记录最新一条。

兑换失败：

- 展示接口错误码对应文案。
- 兑换次数不足时提示剩余次数。

### 5.5 兑换记录

触发：点击“兑换记录”。

前置：

- 未登录：拉起登录。

展示字段：

- 兑换时间。
- 商品名/奖励内容。
- 消耗积分。

分页规则：

- 初始拉取 `pageSize=20`。
- 通过 `lastId` 支持后续分页，当前页面代码主要完成首屏列表。

## 6. 登录与角色校验

### 6.1 登录流程

触发入口：

- 未登录状态点击登录按钮。
- 未登录状态点击兑换、可兑换筛选、兑换记录、VIP礼包、VIP背包等需要登录的功能。
- 登录态失效后重新拉起登录。

登录成功：

- 获取积分商城业务登录凭证 `loginAccessToken`。
- `loginAccessToken` 后续作为接口 `Authorization: Bearer <token>`。
- 获取角色列表与默认角色。
- 有默认角色时自动初始化角色详情、商品列表、积分记录、经验记录、VIP权益。
- 无默认角色时进入角色ID校验流程。

登录失败：

- 保持未登录态。
- 展示错误提示。
- 上报登录失败埋点。

### 6.2 角色列表与默认角色

登录后：

- 按区服/游戏版本调用角色列表。
- 返回角色列表与默认角色ID。
- 如果有默认角色，自动初始化该角色数据。
- 如果没有默认角色，引导用户输入角色ID校验。

### 6.3 输入角色ID校验

用户输入：

- 区服。
- 角色ID。

校验流程：

1. 调用角色校验接口。
2. 校验成功后调用配置中心接口。
3. 发送验证码到角色绑定邮箱/渠道。
4. 用户输入 6 位验证码。
5. 验证码验证成功后换取登录态并初始化页面。

验证码规则：

- 6 位数字。
- 输入一位后自动聚焦下一格。
- 支持倒计时后重发。
- 支持查看“如何获取验证码”引导。

### 6.4 退出登录

退出后：

- 清理 `loginAccessToken`。
- 清空登录态用户信息。
- 返回游客模式。
- 重新拉取游客商品与游客 VIP 权益。

## 7. 积分与经验记录

入口：

- 点击用户信息区“积分”或“经验”数值。

弹窗 Tab：

- 积分记录。
- VIP经验记录。

积分记录字段：

- 变动时间。
- 变动类型。
- 增减数量。

经验记录字段：

- 变动时间。
- VIP等级。
- VIP经验。
- 返利积分。

分页规则：

- 首次加载 `pageSize=10`。
- 滚动到底后继续以 `lastId` 拉取 `pageSize=20`。
- 返回不足一页时停止继续加载。

时间规则：

- 按当前语言配置中的 UTC 偏移进行展示。

## 8. VIP中心功能

### 8.1 VIP等级展示

入口：主 Tab 切换到 VIP中心。

数据来源：

- 游客：游客 VIP 权益接口。
- 已登录：会员权益接口。

展示内容：

- VIP等级名称。
- 等级数字。
- 当前经验 / 等级所需经验。
- 当前等级进度条。
- 升至下一等级所需经验。
- 等级赠送积分。
- 等级礼包入口。
- “敬请期待”占位等级。

交互：

- 使用横向轮播展示等级。
- 默认定位到当前用户等级；游客默认第一级。
- 切换等级时，下方权益列表同步切换。

### 8.2 VIP权益列表

每个等级展示该等级权益：

- 权益图标。
- 权益名称。
- 点击权益后的处理方式。

权益类型规则：

| 字段 | 说明 |
| --- | --- |
| `type=0` | 通用类权益。若用户等级不足，提示等级不足。 |
| `type=1` | 礼包类权益，可弹出礼包领取弹窗。 |
| `type=2` | 充值赠送类权益，可弹出说明或跳转。 |
| `alterType=0` | 点击不弹窗。若有链接则直接跳转。 |
| `alterType=1` | 点击展示弹窗。 |
| `jumpType=1` | 存在跳转链接时可跳转外部链接。 |

### 8.3 VIP礼包领取

触发：

- 点击等级礼包图标。
- 点击礼包类权益。
- 从背包记录中点击礼包。

前置：

- 未登录：拉起登录。
- 已领取：按钮禁用/置灰。
- 等级不足：提示等级不足。

弹窗展示：

- 礼包标题。
- 礼包包含道具。
- 领取按钮。
- 游戏内邮件到账提示。

领取成功：

- 调用礼包领取接口。
- 展示成功提示。
- 禁用领取按钮。

### 8.4 充值升级

VIP中心顶部按钮：

- 未登录：展示“查看我的权益”，点击拉起登录。
- 已登录：展示“立即升级”，点击跳转充值页。

充值跳转规则：

- 若有 `gameVersion` 与 `actorId`，充值 URL 携带这两个参数。
- 否则跳转通用充值页。

### 8.5 VIP背包

入口：

- 仅在 VIP中心 Tab 时展示浮动背包按钮。

前置：

- 未登录：拉起登录。

展示字段：

- 领取/兑换时间。
- 礼包/权益名称。

分页：

- 初始 `pageSize=20`。
- 滚动到底通过 `lastId` 继续拉取。

点击背包项：

- 根据 `giftId` 在当前 VIP 权益中反查对应礼包。
- 打开礼包详情弹窗。
- 领取按钮置为禁用，表示历史记录查看。

## 10. 接口需求

接口基础域名按环境区分：

- 测试环境：测试 points-mall API。
- 正式环境：正式 points-mall API。

公共请求头：

- `Authorization: Bearer <loginAccessToken>`。
- `Content-Language`。
- `points_env` Cookie，GET请求使用。
- POST请求 `Content-Type: application/json`。

签名：

- `/configCenter/v2?` 与 `/login/token?` GET请求需要按参数排序后拼接密钥生成 MD5。
- `/product/trade?`、`/privilege/receive-gift?`、`/login/VerifyCode?` POST请求需要追加基础签名参数。

接口清单：

## 12. 异常与错误码

统一处理规则：

- 接口超时：提示接口超时，解除按钮禁用。
- `code=0`：成功。
- `code=1012`：允许回调处理，常用于兑换次数不足等业务提示。
- `code=1300`：验证码相关提示，允许回调后展示提示。
- `code=2001`：允许回调。
- `code=401`：登录失效，清理 token，重新拉起登录。
- `code=1302`：验证码错误，展示验证码错误状态。
- `code=1301`：映射为通用验证码错误提示。
- 其他错误码：展示对应多语言 `returnTips{code}`。

## 13. 埋点需求

现有埋点平台：`thinking`。

基础配置：

- `appId` 按环境配置。
- `serverUrl=https://data.q1.com`。
- `gameId` 为当前游戏 ID。

事件：

| 事件名 | 触发时机 |
| --- | --- |
| `visit_page` | 游客进入页面。 |
| `click_the_login_button` | 点击登录按钮。 |
| `login_popup_duration` | 登录弹窗停留时间。 |
| `verify_popup_duration` | 验证码弹窗停留时间。 |
| `click_login_tips` | 点击验证码引导。 |
| `role_verification` | 角色校验成功/失败。 |
| `obtain_login_verify` | 获取验证码失败。 |
| `verification_code_verification` | 验证码校验失败。 |
| `recharge_button` | 顶部获取积分按钮。 |

## 15. 非功能需求

兼容性：

- PC 与移动端自适应。
- 移动端按 1080 设计稿 rem 适配。
- 支持主流移动浏览器、Chrome、Safari。

性能：

- 首屏静态资源建议 CDN 化。
- 商品图与权益图需要压缩。
- 接口超时时间 30 秒。

安全：

- 登录 token 存储在 localStorage。
- 签名密钥需妥善管理，避免长期暴露在前端。
- POST兑换、礼包领取等敏感操作必须服务端再次校验积分、角色、库存、次数、等级。

可维护性：

- 配置与业务逻辑分离。
- 多语言文案统一维护。
- 错误码统一维护。
- 商品/VIP资源支持兜底图。

## 16. 验收标准

### 16.1 游客态

- 未登录进入页面，可正常展示商品列表。
- 未登录进入 VIP中心，可正常展示游客 VIP 权益。
- 点击兑换、可兑换筛选、兑换记录、礼包领取时，正确拉起登录。
- 可切换语言，页面文案和接口语言同步变化。

### 16.2 登录态

- 登录成功后可获取角色列表。
- 有默认角色时自动初始化角色详情。
- 无默认角色时可通过角色ID和验证码完成校验。
- 登录后展示角色信息、积分、经验、VIP等级。
- 切换角色后商品、积分、VIP权益、记录全部刷新。
- 退出登录后恢复游客态。

### 16.3 商品兑换

- 全部商品列表展示正确。
- 可兑换筛选准确。
- 积分不足时展示积分不足弹窗。
- 兑换数量校验正确。
- 兑换成功后积分扣减、次数更新、成功提示展示。
- 兑换记录可查看。
- 商品图加载失败时展示本地兜底图。

### 16.4 VIP中心

- VIP等级轮播展示正确。
- 当前等级定位正确。
- 等级进度条计算正确。
- 权益列表随等级切换。
- 等级不足权益提示正确。
- 礼包弹窗展示正确。
- 礼包领取成功后按钮禁用。
- 背包记录可查看，滚动分页可用。

### 16.5 异常

- token 失效自动退出并重新登录。
- 接口超时有提示。
- 验证码错误有明确提示。
- 接口错误码均能映射到多语言文案。
